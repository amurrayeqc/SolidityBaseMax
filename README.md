# SolidityBaseMax

SolidityBaseMax is an Enterprise-grade, Cloud-based framework that optimizes multi-threading and load-balancing within complex system architectures.

SolidityBaseMax is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/SolidityBaseMax.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

SolidityBaseMax is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
